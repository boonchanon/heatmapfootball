# เว็บแอปวิเคราะห์วิดีโอ

เริ่มเว็บแอปจากรากโปรเจกต์:

```powershell
.venv\Scripts\python.exe tools\web_app.py
```

จากนั้นเปิด [http://127.0.0.1:8001](http://127.0.0.1:8001) ในเบราว์เซอร์

หน้าเว็บรับ MP4, MOV, AVI และ MKV (สูงสุด 2 GB) แล้วทำงานตามลำดับนี้:

1. ตรวจจับ/ติดตามและคำนวณพิกัดสนาม
2. สร้างวิดีโอ review ที่มีกรอบและพิกัด
3. สร้าง heatmap แบบโต้ตอบ

ผลลัพธ์ของแต่ละงานอยู่ใน `outputs/web_jobs/<job-id>/` และแสดงบนหน้าเว็บเมื่อเสร็จ งานจะประมวลผลทีละงานเพื่อไม่ให้ TrackLab ทำงานชนกัน

เว็บแอปใช้ inference environment เดิมของโปรเจกต์ จึงต้องให้ `.venv` มีโมเดลและ dependencies พร้อมก่อน โดยเลือก `MVP` เป็นค่าเริ่มต้นสำหรับการลองคลิปแรก
